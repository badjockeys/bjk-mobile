# bjk-mobile

The Bad Jockeys mobile app (React Native), shipped through TestFlight and Google Play.

Not started yet: the web app in [bjk-core](https://github.com/badjockeys/bjk-core) (`src/web`) comes first. The app will call the same API, using a client generated from its OpenAPI document.

Default branch: `master`. Work on `feature/*` branches and open a pull request.
